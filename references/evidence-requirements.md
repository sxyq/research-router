# 证据要求

| 场景 | 最低证据 | 深层证据 |
| --- | --- | --- |
| 修 Bug | 错误原文、版本、可复现现象、解决方案链接 | Issue 讨论、修复提交、相关源码、回归测试 |
| 开源项目/Skill 发现 | 官方仓库、README、Skill 文件、许可证 | 目录树、入口源码、适配器、依赖、测试、Issue、Release |
| 论文发现 | 标题、作者、年份、官方页面或 arXiv | 论文 PDF 正文中的支持段落、方法/实验位置、引用映射 |
| 社区论坛调研 | 公开版块、RSS 或帖子链接 | 帖子正文、多页回帖、作者/时间等页面元数据；经验结论需标注来源和局限 |

## 证据状态

- `verified`: 已打开并核对对应原始内容。
- `partial`: 只有 README、摘要或搜索结果，不能支持深层结论。
- `unavailable`: 页面、登录态或工具不可用。
- `contradicted`: 不同来源存在未解决冲突。

GitHub 的星标、README 声明和实际源码是三个不同证据层；论文标题、摘要和正文也不能混为一谈。
